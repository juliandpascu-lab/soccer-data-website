Methods / data notes

What exactly is one row?

Loading the derived row count…

The source match file contributes date, season, league, country, teams, and score. The source event file contributes the player and event measures. We join on id_odsp, remove events with a missing player or missing match join, then group by season, league, country, player, and event team.

Goals, attempts, shots on target, key passes, corners, fouls, cards, substitutions, offsides, handballs, penalties conceded, and recorded assists are all sums of coded events. Goals per event-bearing match is goals divided by distinct joined match IDs. The source contains domestic leagues only; it does not contain national-team international matches.

League and club badge artwork is loaded as visual reference from TheSportsDB and API-Football media. Historical shirt photos are linked to their Football Shirt Culture, Classic Football Shirts, or eBay source pages from each card. The Camp Nou rendering used across the report and dashboard is from FC Barcelona; goal-count overlays and data visuals are original project UI.
